Enludus Shorts Publisher — User Flow

The only user is Enludus (the channel owner). Steps 1–2 happen once; steps 3–6 happen for each video.

1

Create OAuth client

Desktop-app OAuth client in our Google Cloud project; client file saved to .cache/client_secret.json on the operator's computer.

2

Sign in once

python common/upload.py --auth opens Google's consent screen. The channel owner grants youtube.upload. Token saved to .cache/youtube-token.json.

3

Make the Short

gojuon/make_short.sh <seed> records our app's gameplay and composes the video with our narration and music.

4

Review

Operator watches the MP4 and edits the metadata JSON (title, description, tags). --dry-run prints exactly what will be sent.

5

Upload

python common/upload.py video.mp4 meta.json calls videos.insert (resumable). Prints the video URL and logs the ID.

6

Verify on YouTube

Operator opens the video in YouTube Studio, checks it, and it goes live (public or scheduled with publishAt).

Revoking access: myaccount.google.com/permissions → remove "Enludus Shorts Publisher"; the local token file is then deleted. Expected volume: 1–3 uploads per day.
